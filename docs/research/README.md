# Research

Store source-backed feasibility work, provider comparisons, and recommendations
here. Research does not change current behavior or approve a product decision.

Each research note should state its date, question, evidence, assumptions,
recommendation, unresolved risks, and which protected decision still requires
Khang's approval. Do not store credentials, private URLs, personal data, raw
provider payloads, or copied terms that should instead be linked to their source.
